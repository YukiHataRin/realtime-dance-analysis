# Realtime Dance Analysis Frontend

This directory contains the React and Vite dashboard for the Realtime Dance Aesthetics Analysis application.

See the [project README](../README.md) for prerequisites, camera permissions, backend setup, architecture, and the complete launch instructions.

For frontend development:

```bash
npm install
npm run dev
```

The FastAPI backend must also be running on port `8000`.

Other commands:

```bash
npm run lint
npm run build
npm run preview
```
